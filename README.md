# 🌻 专注农场 · Focus Farm

> 风带来故事的种子，时间使之发芽。

一个跑在 **Windows 控制台**里的番茄钟专注养成游戏。把专注时间变成农场的成长：种下作物，用每一段专注去浇灌它，收获资源、解锁荣誉，最终召唤月神。

---

## ✨ 特性

- 🍅 **番茄钟专注**：10 分钟 ~ 2 小时预设专注时长，配套休息提醒
- 🌲 **四大场景**：森林（学科知识）、鱼塘（阅读积累）、牧场（技术栈）、稻田（实践项目）
- 🌱 **成长系统**：种下的物体随专注时长生长（幼苗 → 成长 → 成熟），成熟后入库
- 🛒 **集市 + 仓库**：资源按 3:1 兑换除害道具，清理有害物品
- 🐛 **有害物品**：杂草 / 珊瑚 / 蛇 / 虫子随时间滋生，堆积过多会反噬作物
- 🌙 **荣誉系统**：连续 5 天专注满 14 小时，获得 1 个月亮（纯荣誉收藏）
- 🌕 **月神降临**：集齐 3 个月亮自动召唤，三月亮合体动画
- 📖 **专注记录**：累计次数 / 总时长 / 连续天数 / 最近明细，每一次努力都被记住
- 🌤️ **实时天气**：免费中文天气（uapis.cn，IP 自动定位）
- 🌸 **季节显示**：按春分 / 夏至 / 秋分 / 冬至划分，随系统时间自动变化
- 🌃 **夜间保护**：每天 23:00 – 05:00 强制不计时，提醒你早点休息
- 💾 **自动存档**：按 `Q` 或点关闭按钮都会保存，随时可恢复进度

---

## 🎮 玩法速览

1. 在地图选择一个场景，`Enter` 进入
2. 按 `3` 种下一个物体（树 / 鱼 / 动物 / 作物）
3. 按 `1` 开始专注，选择时长；专注期间物体持续生长
4. 物体成熟后自动入库，获得木头 / 鱼 / 肉 / 作物
5. 去集市 `M` 兑换除害道具，去仓库 `W` 使用
6. 连续 5 天专注满 14 小时可得月亮，集齐 3 个月亮自动召唤月神

## ⌨️ 操作说明

| 按键 | 作用 |
|---|---|
| `↑ ↓ ← →` | 切换子场景 / 场景类型 |
| `Enter` | 进入选中场景 |
| `1` | 开始专注 |
| `2` | 停止专注 |
| `3` | 种植新物体 |
| `4` | 清除有害物品 |
| `D` | 铲除当前物体 |
| `0` | 开始休息 |
| `L` | 封锁 / 解锁当前场景 |
| `R` | 重命名场景 |
| `B` | 返回地图 |
| `M` | 进入集市 |
| `W` | 进入仓库 |
| `H` | 查看专注记录（主菜单） |
| `S` | 切换有害物品生成速度（主菜单） |
| `X` | 重置系统 |
| `Q` | 保存并退出 |

> ⚠️ 请用 `Q` 正常退出，不要直接关闭窗口（点击窗口关闭按钮也会自动保存）。

## 🔧 构建

### 依赖

- **Windows 10/11**
- **MinGW-w64**（g++，需支持 C++17，推荐 posix 线程模型）
- **Python 3**（天气脚本运行所需，仅标准库，无需额外安装包）

> 本项目使用大量 Windows 控制台 API（`ReadConsoleInputW`、`GetStdHandle`、`SetConsoleOutputCP` 等），**仅支持 Windows x86_64**，暂不支持 Linux / macOS。

### 编译

```bash
g++ -std=c++17 -O2 -pthread \
    -o FocusFarm.exe \
    src/main.cpp src/game.cpp src/ui.cpp src/weather.cpp
```

发布单文件静态版（不依赖 MinGW 运行时 DLL）：

```bash
g++ -std=c++17 -O2 -static -static-libgcc -static-libstdc++ -pthread \
    -o FocusFarm-v1.0.0.exe \
    src/main.cpp src/game.cpp src/ui.cpp src/weather.cpp
```

### 运行

```bash
FocusFarm.exe
```

运行时需保证 `scripts/get_weather.py` 与可执行文件处于同一目录结构下（`scripts/` 子目录），且系统已安装 Python 3。

## 📄 技术要点

- 控制台 UI 采用「内存缓冲 + 一次性输出」双缓冲渲染，避免闪烁
- 输入采用 Win32 `ReadConsoleInputW`（宽字符），原生支持中文
- 天气通过 `_popen` 起 Python 子进程、经管道传递 JSON，后台线程定时刷新（15 分钟）
- 存档为自描述文本格式，损坏时给出中文报错而不静默重置
