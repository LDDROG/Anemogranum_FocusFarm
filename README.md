# 🍃 风种子 · 专注农场

> 风带来故事的种子，时间使之发芽。 —— 巴巴托斯

这是一个基于**Windows终端**的番茄钟专注小游戏，专门为考研党设计，也适合所有大学生、中学生等需要专注学习的群体。

## 为什么做这个玩意？

主要是受到开罗游戏和像素游戏机的启发，想搞一个体量极小但功能和逻辑比较有意思、而且还很有用的东西。  
最后决定依靠 Emoji 和最原始的文本尽可能简洁地展示信息，同时还带点温馨之感。

## 只有 Windows 才能用吗？

是，而且只有 Windows 10 及以上才能获得最佳体验，原因是里面使用了大量新版微软 Emoji 和新版 Windows 专属控制台接口。  
Mac 版本以后再说···  
至于移动端，想了一下觉得手机平板很难长时间连续占用，而且对学习来说诱惑力比电脑大多了，所以 ≡[。。]≡

## 特性

- 🍅 **番茄钟**：10 分钟 ~ 2 小时预设专注时长，配套休息提醒。
- 🌲 **场景**：森林、鱼塘、牧场、稻田，方便区分不同专注类型，比如“高等数学”和“FPGA开发”这种放在一起很别扭的。不同场景内部还可以自定义多个科目。
- 🌱 **成长系统**：种下的物体随专注时长生长，成熟后作物入库。
- 🛒 **交易系统**：收获的作物可按 3:1 兑换除害道具。
- 🐛 **有害物品**：随时间滋生，堆积过多会反噬作物。
- 🌙 **荣誉系统**：连续 5 天专注满 14 小时即可获得 1 个月亮。（持续获得月亮说不定可以召唤月神？）
- 📖 **专注记录**：可随时查看每条历史记录。
- 🌃 **夜间保护**：每天 23:00 – 05:00 强制不计时。
- 💾 **自动存档**：按 `Q` 或关闭终端窗口都会自动存档在本地文件 `focusfarm_save.dat`。

## 玩法概览

1. 在地图选择一个场景，`Enter` 进入
2. 按 `3` 种下一个物体（树 / 鱼 / 动物 / 作物）
3. 按 `1` 开始专注，选择时长；专注期间物体持续生长
4. 物体成熟后自动入库，获得木头 / 鱼 / 肉 / 作物
5. 去集市 `M` 兑换除害道具，去仓库 `W` 使用

## 操作说明

| 按键 | 作用 |
|---|---|
| `↑ ↓ ← →` | 切换子场景 / 场景类型 |
| `Enter` | 进入选中场景 |
| `1` | 开始专注 |
| `2` | 停止专注 |
| `3` | 种植新物体 |
| `4` | 清除有害物品 |
| `D` | 铲除当前物体 |
| `0` | 开始休息 |
| `L` | 封锁 / 解锁当前场景 |
| `R` | 重命名场景 |
| `B` | 返回地图 |
| `M` | 进入集市 |
| `W` | 进入仓库 |
| `H` | 查看专注记录（主菜单） |
| `S` | 切换有害物品生成速度（主菜单） |
| `X` | 重置系统 |
| `Q` | 保存并退出 |

> ⚠️ 请尽量用 `Q` 键正常退出。

## 安装和运行

从 Release 下载压缩包，解压即可。运行 `FocusFarm.exe` 启动。

### 依赖

- **Windows 10/11**
- **MinGW-w64**（g++，需支持 C++17，推荐 posix 线程模型）
- **Python 3**（天气脚本运行所需，仅标准库，无需额外安装包）

> 本项目使用大量 Windows 控制台 API（`ReadConsoleInputW`、`GetStdHandle`、`SetConsoleOutputCP` 等），**仅支持 Windows x86_64**，暂不支持 Linux / macOS。

---

## 从源代码构建

```bash
g++ -std=c++17 -O2 -pthread \
    -o FocusFarm.exe \
    src/main.cpp src/game.cpp src/ui.cpp src/weather.cpp
```

发布单文件静态版（不依赖 MinGW 运行时 DLL）：

```bash
g++ -std=c++17 -O2 -static -static-libgcc -static-libstdc++ -pthread \
    -o FocusFarm-v1.0.0.exe \
    src/main.cpp src/game.cpp src/ui.cpp src/weather.cpp
```
